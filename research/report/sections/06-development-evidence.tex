\subsection{Paragraph boundaries around section headings}
The lossless projection treats standalone top-level part, chapter and section
commands with literal titles as opaque boundaries, including subsections and
subsubsections. Paragraph
candidates can be identified on either side without a blank line. Source-model
checks preserve the heading bytes, refuse reordering across the heading and
allow a supported reorder within one section. A literal label on the same or
immediately following line is retained with the heading. Numbered headings can
carry a literal short title in brackets. Standalone \texttt{\string\newpage}
and \texttt{\string\clearpage} are opaque boundaries. A reorder can take place
on either side of a page break, subject to the same source and rendered checks.
Paragraph reordering retains a standalone \texttt{\textbackslash{}par} separator in
its original source slot, including its surrounding whitespace.

\subsection{Adjacent paragraph reorder as a protected source draft}
\label{sec:adjacent-paragraph-draft}
The source planner accepts two references to plain paragraphs in the same
file and revision. The requested position is immediately before or after the
neighbor. Swapping the two source ranges keeps the separator and all other
bytes intact. One history entry covers the two writes and Undo restores the
earlier bytes and selection. The planner refuses intervening content,
opaque syntax, cross-file moves and invalid references. Byte-identical
paragraphs and an already satisfied order leave source and history unchanged.

Six targeted core regressions cover the order, bytes and file boundaries,
Undo/Redo, repeated text, multibyte text and stale references. The native
tests submit both handles through the protected draft command and confirm
their recovery revision, receipt reuse and refusal behavior. The browser
protocol checks the two handles and explicit logical direction before the
request is sent. Applied receipts retain the unresolved render obligation.

Three Latin single-page fixtures covered moving upward, moving downward and
moving the second of two equal paragraphs across its distinct neighbor. Each
candidate matched a separately specified source byte for byte. We compiled the
original, candidate and reference with pdf\LaTeX{}, Xe\LaTeX{} and Lua\LaTeX{}.

each differed from its baseline. The rendered-order diagnostic invokes the
core candidate example. Native recovery and history are exercised by the

\subsection{Free positioning in ordinary LaTeX}
A supported single typeset line can be displaced without declaring a
Texloom package in the saved document. The source edit uses
\code{\textbackslash raisebox} for vertical motion and a pair of opposed
\TeX{} kerns for horizontal motion. Explicit height and depth arguments retain the
line's vertical contribution to normal flow. A group feasibility probe found
that leaving these arguments implicit moved text below the selection. A second move updates the same
source construction. Restoring the original offset removes it.

Two private tagged builds identify the selected glyphs before and after the
move. Both have to match their respective unmarked PDFs. The native worker
then translates the tagged baseline target and compares the candidate
against that prediction, including the complete page rasters. Unsupported
line structures or rendering differences refuse the operation before
history changes. This analysis remains distinct from moving material to a
different position in the source order.

The regression fixture is a three-page Article. It tests two successive
displacements of the first sentence, requires its neighbor and both later
pages to stay put, and checks exact source, Undo/Redo, explicit
Save, reopening and an external build. Its evidence is scoped to this fixture
and the tested engine configurations. Physical pointer interaction is
checked separately.

\subsection{Verified reorder within a run of source paragraphs}
The PDF gesture exposes insertion cues above and below text lines. A
drop must resolve to the edge of an independently identified destination
paragraph. The planner moves the selected paragraph within an uninterrupted

one unit.

Private builds tag every affected paragraph with a distinct identity. The
independent inspector checks the tagged and untagged PDFs for identity before
checking that the run remains on one page, every marked paragraph has the
expected visual order, and glyph multiplicities are preserved. Source and
history change only after approval. The regression exercises both directions,
exact source, Undo/Redo, Save, reopening and an external compile.

At a page break an opening marker in vertical mode could attach to the

rasters, identified the complete first paragraph of page two, and reordered
it below its neighbor with exact source bytes. Moves across pages and
structured-source reorder require separate policies.
